# Mojo

The Mojo language for the OpenIDEA fork: `.mojo` and `.🔥` files with Python-style highlighting,
`#` comments, four-space indentation and the Mojo fire icon (light and dark).

Install it with `openidea-plugin link plugins/mojo`. With the fork's Mojo feature (`FORK.md`), the
project's Mojo SDK then provides the language server, **Reformat Code**, running and debugging.
