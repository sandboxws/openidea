# Spark SQL

The `.sparksql` file type for the OpenIDEA fork: SQL highlighting, `--` and `/* */` comments,
four-space indentation and a file icon (light and dark).

Install it with `openidea-plugin link plugins/sparksql`. With the fork's Spark feature (`FORK.md`),
**Run in Spark** and **Explain in Spark** run the statement at the caret (or the selection) in the
selected connection's session, Spark Results shows the rows or the plan, and the session's catalog
completes table and column names. **New Spark SQL File** creates one among the scratch files.
